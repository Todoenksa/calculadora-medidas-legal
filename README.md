# Calculadora Vidrio — Legal

Política de privacidad pública de la app **Calculadora Vidrio** (Todo en Ksa INC).

- Página: https://todoenksa.github.io/calculadora-medidas-legal/privacidad.html

Este repositorio solo contiene la política. Los archivos HTML se generan desde los textos de la app
(`assets/legal/*.md`) con `tool/generate_privacy_html.py`, para que la app y la web muestren el mismo texto.
